## Description

**KStars** is a free, open-source, cross-platform astronomy software that provides an accurate graphical simulation of the night sky from any location on Earth, at any date and time. It includes up to 100 million stars, 13,000 deep-sky objects, all 8 planets, the Sun and Moon, comets, asteroids, supernovae, and satellites. KStars is part of the KDE Education Project and is designed for students, teachers, and amateur astronomers.

## About This Package

This is an **Aurelis Linux** package for KStars, built as an AppImage. It can also run as a regular AppImage on any Linux distribution without installation.
